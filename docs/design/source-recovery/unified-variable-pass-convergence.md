# 统一变量恢复的全过程Pass收敛合同

2026-10-11设计及整包验收；**规则311完成P1–P6，主干第4项按本轮普通变量范围关闭**。
原65项、10项保留、最终成本与冻结证据见文末；历史候选/失败记录仅保留经过，
不能代替最终完整结果。共同投射求解的分析固定点与这里的优化固定点分别验收。

## P1：变更集必须来自实际提交

每个pass读取某一不可变revision，先拥有候选delta，再原子提交；提交期间禁止查分析。
引入typed `RecoveryChangeSet`，字段按语义分：值/读取替换、执行与完成、定义/初始化、
存储等价类、绑定生命期/名字、纯语法。记录受影响的ExprId/StmtId/SymbolId及旧/新事实域。
空delta不递增revision、不入队。不得用“哪个pass运行过”代替真实变更集。

字段覆盖账本必须包含BindingInitializers全部可变表：statements、omitted、
statement_values、forwarded_values、loop_declarations、primitives、literals、
read_literals、read_bindings、read_sources、aliases、storage、undefined_stores、
declaration_values、declaration_completions、replacements、transports。
evaluations/normal_stores/entry_counts是最终派生事实，不允许作为独立优化写入口。

typed delta发表层检查“实际改动 ⊆ 声明变更域”，异常/失败不能发表半份计划；
遗漏失效域、空写伪装进展属于内部错误。试算继续使用同一共同投射提供者。

## P2：失效与重跑由依赖决定

`PassContract`扩展为读域、可写域、阶段、前置义务、进展见证。
变更经单一域依赖表传递到分析：

| 实际变化 | 至少失效的共同事实 |
|---|---|
| 值或read来源、transport | expressions/flow及其联合初始化/值域解；引用/名字；live/demand/constants/copies/statements/cycles |
| 执行/控制/效果/完成/异常 | flow联合解和全部下游控制、定义、活跃、移动事实 |
| 定义/初始化/生命期 | flow联合解、initializations、live/demand、常量/复制、名字/干涉/loop entries |
| storage/aliases | 绑定投射、名字、flow联合解及下游事实；不能只失效干涉 |
| 已证明纯语法 | grammar产物；必须证明共同执行/身份/初始化不变，否则归入上面语义域 |

先保守失效整个受影响分析域，保证正确；后续才做图内区域增量，不能以增量精度
作为本轮关闭条件。每个pass按输入域epoch记录最近稳定尝试；全局revision继续
防止借用旧对象，但不得要求无关域变化后的pass无条件重跑。

去重有界队列最多容纳当前阶段15个pass。任何影响其输入/候选生成域的提交都使其
重新入队，包括提交者自身；只有证明一次调用内部已经穷尽当前候选时才可省略自身。
no-op必须记录读取的域版本。队列为空且阶段前置义务有效，才允许越过barrier。

## P3：有依赖的顺序保持显式

阶段内部仍显式区分 Values → Storage/Motion → ReadValues，前置清理保持
DeadDefinitions → InitialValues → Bindings。每次实际变化通知当前阶段所有输入域
相交的消费者，包括提交者；固定容量队列去重并循环取出，已有待执行消费者不会
因为更早的pass再次入队而被无限推后。顺序只调度工作，不作为语义准入。

阶段末检查全部非Grammar pass的稳定输入epoch；后阶段改动使前阶段失效时，
显式回到Values。没有固定第二轮，也不因跨barrier而清空未变化输入的no-op证书。
联合分析依旧以完整revision为所有权边界，不能把pass尝试证书当作分析可借用证明。

为使回边可以重新检查storage/motion，BindingValues改为实际ExprId读取替换，
不再发表全槽read_bindings。常量/复制共同分析只选择当前private读取；已替换读取
指向不可合并的入口/非private单元，因此退出候选集合。后续当前和trial都看到它的
真实引用、名字、单元与效果，不借用先前的移动目的地证明。

初始共同图的复制边作为不可变存储偏好保留；每轮先映射到当前代表，再用当前
干涉、初始化、生命周期与名字事实验证。历史偏好不能证明可合并，也不继承旧的
非干涉结论。它避免删除复制后丢掉候选机会，不按源码或指令布局重建偏好。

Grammar为最终两项有限任务。循环entry/单元/初始化已由共同投射提供者提前适配；
final pass发表相同语法选择，const由最终写入事实决定，禁止再开语义优化回边。

## P4：终止必须有可检查的进展依据

不能使用固定轮数、规则号、deadline或work budget作为算法终止证明。
预算只负责typed资源失败；失败保留原表示/既定错误，不发表半份候选。

每类delta带进展见证：删除/transport消耗仍存活的原始执行/写入/复制义务；
合并严格减少存储等价类；值事实从未知变为已证明值；纯声明选择单向封存。
同一结果反复写回不算进展。替换链必须指向共同证明的代表元并有无环/严格秩依据，
不能靠SymbolId数值、arena顺序或名字构造语义。

当前候选实现由RecoveryProgress消费实际journal，对每次非空语义事务检查：

- replacement、transport、逐读取literal/read来源、全槽literal是单向发表；已发表
  的值与表达式替代不可在后轮改写成另一个目标。
- 原始assignment转成声明initializer、声明初值退役、声明目标写入消除、
  statement residual、forwarded RHS及omission，各自消耗对应原始ExprId/StmtId义务。
  独立位图不允许删除表项后重新消费同一个义务；omission不能从1退回0。
- alias/storage的新等价关系进入路径压缩、按秩合并的DSU。代表元规范化不算新的
  合并；只有减少类数才算进展。DSU的数值秩仅用于成本，与源码代表选择无关。
- 声明位置、kind、undefined目标和完成信息的辅助改写必须伴随上述真实进展；
  单独改这些字段不能触发下一轮。Grammar受单向终态控制，不参与重复轮次。

设原始表达式数E、语句数S、绑定数B，则最多消费5E+5S+B个原始义务及max(B-1,0)
次类合并。每个非空语义事务至少消费一个，故有效提交数有有限上界；空事务只记录
输入epoch，不递增revision。每个提交最多通知固定数量的消费者，稳定epoch沿barrier
保留，未发生新提交时至多完成一次阶段遍历后退出。预算不足仍是资源失败，不能当作
这个终止论证的一部分。检查失败是内部进展契约错误，不是新的输入恢复限制。

这份上界不等于线性总耗时：全图重建、候选试算和稀疏事实成本仍按P5单独验收。
进展见证的定向/实际消费者验证和整包检查未全部完成前，不能关闭P4或C。

## P5：成本按整个过程计量

统一累计：候选扫描、队列弹出、提交、事实重建、trial、活跃事实/边传播、保留与临时字节。
报告N节点/E边/F稀疏事实/M有效提交，复杂度为各实际重建与传播成本之和；
不能拿一次分析O(N+E+F)当作整个优化过程同阶。即使轮数≤N，全图重算N次也可能是二次。

优先批量候选和输入域epoch去重。若200/201/400/800的链式机会仍触发逐节点全图重跑，
必须增加共同候选索引/受影响工作集，不能用200阈值禁用优化或降低验收。
记录密集事实真实成本，资源不足走既有typed路径；不得丢弃语义换取曲线。
