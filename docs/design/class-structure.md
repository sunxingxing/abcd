# Class Creation and Member Evidence

Continue structural recovery before body expansion. Ordinary modern
DEFINECLASSWITHBUFFER provides caller-region constructor and literal slots,
observable constructor length, and a register containing the parent value.
The parent register is evidence, not a proven extends expression/class name.

Pinned ets_runtime LiteralDataExtractor::EnumerateLiteralVals consumes a method
tag plus METHODAFFILIATE as one function-template value. ClassInfoExtractor
uses the final integer as the number of prototype property pairs; remaining
pairs are static. Preserve order and duplicates, getters/setters/generator kinds
and affiliate lengths. Do not call prototype properties instance fields.
Method payloads are direct entity references, not caller-region pool slots.

Implement a bounded linear class-buffer parser and typed class creation lift;
then integrate method creation-site evidence into record JSON. Build method
membership lookup once per file. Stream one decoded method/current literal at
a time. Keep failed/unsupported sites explicit and do not produce speculative
class declarations or method bodies. The initial surface is ordinary modern
classes; deprecated/sendable formats need separate adapters, not guessed reuse.

Tests: split counts, empty class, method-affiliate collapse, duplicate keys,
getter/setter/generator and scalar values, malformed tails/pairs/references,
200/201/geometric scaling and memory rejection. Verify constructor/member
targets against actual method membership and paired sample records. Follow with
constructor-store field analysis, exported/global class identity and source
signatures; function length remains distinct from ABI/source parameter count.
