# Nested synchronous iterator close

`main.js` is compiled by the pinned dynamic es2abc at O0 and default; build.json
records exact commands and hashes. Only ABC enters the engine. The callback can
throw, and `stop` returns the current inner value across both closes.

The O0 fixture exercises close-entry derivation and independently verified
priority for all four close copies. It is NOT a publication/differential pass:
private-state and nested-body dispatch ownership are still missing. The default
fixture currently stops earlier at ExceptionPlan input/layout PC450. The test
must not replace either refusal with a claimed native for-of completion.
