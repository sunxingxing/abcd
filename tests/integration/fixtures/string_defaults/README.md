# Direct SSA string defaults

`defaults.js` is an independent Node oracle. The decompiler receives only
`defaults.abc`. Generated by the DevEco SDK es2abc at the path below, ABC
24.0.0.0. Compiler SHA-256:
`4d921b123d050309231436be967860a2facb79cd2c241b5b37f3b08f74b54bca`.

```sh
/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/ets/build-tools/ets-loader/bin/ark/build-mac/bin/es2abc \
  --module --merge-abc --opt-level=0 --record-name=defaults --source-file=defaults.js \
  --output tests/integration/fixtures/string_defaults/defaults.abc \
  tests/integration/fixtures/string_defaults/defaults.js
```

Constructor m543 has undefined tests at PC15/30, string pool9 at PC20 and
integer 65280 at PC35. The CLI test independently checks pool-string and
integer instructions and both undefined tests for Logger, sequence, leading
and arrow before executing engine output. `sequence` has string/numeric/string
defaults; `leading` has a required parameter before its defaults.

The Node differential runs 44 cases per contract (88 total): missing arguments,
explicit undefined, null, empty string/zero, explicit overrides, Unicode/newline
constants, observable left-to-right conversion of explicit objects and a throwing
conversion. It compares values, exception constructors, full conversion traces,
and native `.length` (0/0/1/0). These are constant default initializers; this does
not claim support for arbitrary effectful default expressions, earlier-parameter
default references, or cell-backed captured defaults.

Four source mutants per contract change the string, change the number, swap
initializer values, and remove the first initializer. All must differ from the
unmutated oracle; the last mutant checks observable `.length` too. IR tests
separately reject wrong pool identity, wrong parameter/order/producer and a
numeric operation forged as a string; signature tests reject swapped/default
expressions, wrong resolved text and missing initialization. Pool resolution
also rejects an out-of-range slot. No finally-throw scenario occurs here.
